A plain, working household budget site: one household's monthly plan in four pages. The home page shows the budget overview — what was planned, what was spent, and what is left in each category — plus income, expenses by category, and savings goals. The income page lists every income source with a working add form. The expenses page breaks spending down item by item, category by category. The savings page tracks each goal with a progress bar and lets the household add a new one. Every figure is real, every control works, and nothing is a placeholder. It is plain static files: no build step, no network requests, and it works on a desktop and on a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Any static file server works too — serve `app/` at its root.
